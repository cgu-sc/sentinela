Escala e tempo total

35 mil CNPJs: a primeira rodada levou cerca de 30 dias; hoje, a estimativa é de 4,1 dias em processamento sequencial.

Cálculo dos indicadores

Após o processamento de cada CNPJ, são calculados os demais indicadores necessários à auditoria e à classificação de risco.

Processamento dos indicadores

A execução da etapa leva aproximadamente 10 dias, usando a produção do Farmácia Popular como fonte primária, com cerca de 2,2 bilhões de registros.

2. Sistema Web

Principais tecnologias do frontend e backend
Sistema WebFrontend e backend
principais tecnologias

Frontend

Vue 3 e Node.js para interface, dependências, desenvolvimento e build.

Visualização

ECharts e Cytoscape.js para gráficos, mapas e grafos.

Backend Python

Python + FastAPI com Uvicorn/ASGI; Polars engine de processamento e cache; Pandas para manipulação e integração.

Aplicação desktop

PyWebView e PyInstaller para execução e distribuição do sistema.
